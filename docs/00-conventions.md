# 文档规范

本文定义 `docs/` 的统一结构、写作方式和完整性标准。规范沿用 rl-bridge，使在两个项目
之间切换的读者看到相同的形状。

## 1. 文档边界

设计文档记录可观察行为、状态所有权、跨模块契约和正确性约束，不逐行翻译实现。

以下内容必须记录：

- 会改变输入、输出、状态、资源或失败结果的逻辑。
- 进程之间、HTTP 之上、以及对外部存储的协议。
- 并发、顺序、幂等、retry、timeout 和 backpressure 语义。
- 配置、指标、日志和恢复行为。
- 由测试证明的重要约束。

私有辅助函数只有在影响以上行为时才需要单独说明。

## 2. 权威位置

| 信息 | 位置 |
|---|---|
| 系统设计原因 | `02-architecture/` |
| 单个模块职责和内部状态 | `03-modules/` |
| 跨进程消息顺序和 schema | `04-protocols/` |
| 运行和排障步骤 | `05-operations/` |
| 测试证据 | `06-testing/` |
| 配置、endpoint、指标等穷举信息 | `07-reference/` |
| 状态、决策、计划 | `08-project/` |

同一事实只在一个位置完整定义。其他文档使用链接和一句上下文说明。

## 3. 文件与语言

- `docs/README.md` 是 GitHub 自动展示的目录入口，不加序号。
- 其他文档使用 `<NN>-<topic>.md`，其中 `NN` 是当前目录内的两位阅读序号。
- `00-` 只用于目录入口之后、正式内容之前的元规范；普通内容从 `01-` 开始。
- 序号在每个目录内独立递增，并与 `docs/README.md` 中的顺序一致。
- 文件名除序号外只使用小写英文和连字符。
- **正文使用中文。**
- **术语与标识符保留英文**：类、函数、配置项、指标、endpoint、环境变量、协议名称，
  以及本项目的固定概念名。标识符使用反引号。
- 固定术语：Slot、Incarnation、Lease、Cell、Node Agent、Registry、Reconciler、
  Readiness、Admission、membership、discovery、fencing、generation、
  desired state、observed state、control plane、data plane。
- 当前规格文档使用陈述句。由于本目录整体是提案，索引和每篇文档的摘要都必须明确标注
  “提案；当前未实现”。
- 不使用源码行号。链接到稳定的文件路径、类名或测试名。

## 4. 模块文档模板

模块文档按以下顺序组织。没有对应内容时写“无”，不能直接省略影响判断的章节。

```markdown
# <Module>

> 一句话说明模块解决的问题。

## 1. 范围
## 2. 职责
## 3. 非职责
## 4. 系统位置
## 5. 依赖
## 6. 公共契约
## 7. 状态所有权
## 8. 生命周期
## 9. 主流程
## 10. 并发与分布式语义
## 11. 正确性不变量
## 12. 故障处理
## 13. 配置
## 14. 可观测性
## 15. 测试
## 16. 限制与取舍
## 17. 源码映射
```

非职责必须指出由哪个模块负责，这是防止边界逐渐模糊的唯一手段。

## 8. 图表

- 系统关系使用 Mermaid `flowchart`。
- 请求和数据顺序使用 `sequenceDiagram`。
- 生命周期和控制状态使用 `stateDiagram-v2`。
- 图中节点使用稳定角色名，不使用临时变量名。
- 每张图后列出图中无法表达的顺序、失败和不变量。

## 9. 数字

每个数量必须标注三种来源之一：

| 类别 | 含义 |
|---|---|
| **实测** | 由本仓库的 benchmark 或测试产生，并注明命令 |
| **推导** | 由明确假设计算得出，算式必须可复算 |
| **待测** | 冻结设计前必须获得，并注明采集位置 |

没有标注来源的数字是伪装过的猜测。`tests/test_docs.py` 会重新计算这些页面里的推导值，
与页面自身的算式不一致即失败。

## 10. 完整性标准

文档完成必须同时满足：

- 模板章节全部存在。
- 非职责指明了归属模块。
- 每个状态都有 owner 和生命周期。
- 每个协议都写明顺序、timeout、retry 和幂等性。
- 每个故障模式都写明由谁检测、在什么时限内。
- 每个数字都带来源类别。
- 每条“由测试证明”的断言都指明测试名。
- 全部相对链接可解析，且每个页面都能从索引到达。

最后两条由 `tests/test_docs.py` 强制。
